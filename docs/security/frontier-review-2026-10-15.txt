Frontier security follow-up — 2026-10-15 (Asia/Tokyo)

Scope
- Follow-up to frontier-review-2026-10-14.txt, using the final local source.
- This is a scoped review, not a guarantee that all bugs or vulnerabilities
  are absent. Exchange settlement and third-party gateways were not audited.
- No real entry, cancellation, close, payment or automatic-trader launch was
  performed. Existing live backend containers were not restarted.

Remediation
- Legacy built-in provider credentials are removed from current source.
  Legacy nofxos constructors fail closed without Claw402, including explicit
  legacy URLs and keys. Regression tests confirm zero direct-origin requests.
- Binance protection-order read errors fail closed. Testnet accounts cannot
  silently obtain a mainnet planning/inspection client.
- Hyperliquid uses the configured unified-account flag. Complete account reads
  fail if the mainnet xyz market cannot be read, instead of returning a falsely
  complete core-only portfolio. Regression fixtures cover success and outage.
- xyz helpers respect the configured API origin. Testnet position reads skip
  mainnet-only xyz markets instead of querying the mainnet endpoint.
- Go 1.26.9 and updated golang.org/x modules remove previously reachable
  advisories. Docker and CI use the same declared Go version.
- Frontend production dependencies were updated. Tailwind 3's vulnerable build
  dependency chain was removed through the official Tailwind 4 migration,
  including class compatibility changes. Node 24 is used by Docker and CI.
- Local Compose and Vite bind to 127.0.0.1 by default. Existing running Docker
  containers still publish on 0.0.0.0 until explicitly recreated. Changing
  source configuration does not retroactively change existing listeners.

Billing boundary
- AI500 and supported paid holder analytics use authenticated Claw402 routes;
  no legacy origin fallback is permitted. Unknown paid outcomes never trigger
  automatic repayment/retry. A missing paid leaderboard route is unavailable.
- Owner-configured direct AI providers remain an intentional NOFX capability:
  they bill the selected provider using that owner's key, not Claw402.
- Public exchange candles, funding, open interest and local deterministic
  calculations are intentionally free. Claw402-only AI monetization is not
  claimed or silently imposed.

Credential recheck
- Eight configured sensitive .env values: zero exact matches in tracked source,
  the latest 30 local Git commits or the generated production frontend assets.
- .env remains mode 0600 and ignored, as do the database and generated assets.
- The previous review checked both stored nonempty credentials: ENC:v1 at rest,
  no matches in then-current source/history/logs/running frontend assets.
- A previously built-in upstream credential still exists in historical Git
  commits. Removal is not revocation. The issuer must revoke it if still valid;
  its validity/revocation was not tested. History was not rewritten.
